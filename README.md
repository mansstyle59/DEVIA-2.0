# DEVIA 2.0 — Starter MVP

Socle autonome de départ pour l'application de devis artisan.

## Fonctionnalités du prototype
- Interface responsive mobile / ordinateur, identité bleu nuit et violet.
- Formulaire client et description de chantier.
- Dictée vocale française lorsque le navigateur la prend en charge.
- Ajout / suppression de prestations.
- Calcul automatique HT, TVA et TTC.
- Enregistrement local des devis dans le navigateur.
- Impression / export PDF via le navigateur.
- Logo SVG, manifeste PWA et safe areas iPhone.

## Tester
Ouvrir `index.html` ou lancer `python3 -m http.server 8000`.

## Limites
Ce prototype n'a pas encore de compte utilisateur, base distante, synchronisation cloud, génération IA de prix ni signature électronique. Les données restent sur l'appareil. Ne pas utiliser avec de vraies données clients avant sécurisation, conformité RGPD et sauvegarde.
