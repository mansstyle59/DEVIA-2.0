# Déploiement DEVIA 2.0

Le dépôt GitHub est connecté à Cloudflare Pages pour publier ce prototype statique.

- Framework preset : None
- Build command : aucune
- Build output directory : `/` ou `.` selon l'interface Cloudflare

Le prototype fonctionne sans clé API. Les fonctions IA, comptes, base distante et synchronisation restent à développer.
